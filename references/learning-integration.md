# 学习、整理与复习的衔接

仅在当前请求涉及整理、记忆、制卡、复习或继续旧主题时读取。这里规定组件交接，不建立新的课程系统、数据库或调度器。

## 按意图调用已有能力

| 用户当前需要 | 行动 |
| --- | --- |
| 解释、看懂、练习、处理误解 | 留在 `learning-lab`，不自动写笔记或导入 Anki |
| 登记我学过什么、纠正经验归属、查可迁移的旧知识 | 使用 `learning-lab` 的个人知识库入口，按[本地写回约定](knowledge-writeback.md)及库内统计约定维护经历和能力 |
| 整理这次学习、留下参考、记住重要内容 | 读取 `ai-learning-review`，提炼少量有来源的候选，分清记忆、参考和练习 |
| 把某词、表达、句子或音视频语境做成卡 | 读取 `anki-context-card-maker`，保留原句与定位，准备预览，再按既有授权写入 |
| 同一材料同时学知识和语言 | 复用材料，按不同检索目标分别交接；不重复要求用户提供已知信息 |
| 复习或继续之前的学习 | 从用户指定或已有配置中的真实记录恢复；按表现决定回忆、重讲、练习或改卡 |

使用对应组件前读取它的 `SKILL.md`，只加载当前需要的参考。缺少某组件时仍可完成解释或候选草稿，说明尚不能执行的保存/导入，不声称已完成。

## 共享上下文，保留各自格式

交接携带已有的必要信息，不另造一份必须填写的 JSON：

- **来源与定位**：文件/URL/对话来源，以及段落、页码、公式号、原句或时间戳。只能引用真实可定位的内容。
- **学习目标**：要理解或使用什么；制卡时说明具体检索目标，避免只有主题名。
- **原始情境**：哪些条件决定答案，哪些是示例或假设，哪些仍待核实。
- **已有表现**：用户真实作答、解释、误解与修正；没验证的理解保持未验证，不填造掌握度。
- **下一步与去向**：记忆/参考/练习的选择，以及用户已指定或配置的输出目录、牌组、语言。

通用回顾继续使用 `episode_capsule`、`candidates`、`source_ref` 与现有 `id`；词句卡继续使用 `lookups.json`、完整 `sentence`、来源、可用时间戳与 `InstanceKey`。不要把两种数据格式硬并成一个卡型，也不重新生成已有标识来规避去重。

源材料是共同依据。对同一词在不同真实句子中的实例，沿用语境卡的独立实例规则；对同一知识卡的再次整理，沿用通用回顾的稳定 ID。不同类型确实训练不同目标时可以共存。

## 选择值得留下的内容

- **记忆**：稳定、反复会用、遗忘成本高，适合主动提取的线索、关系或表达。
- **参考**：需要以后搜索恢复的概念模型、方法与判断依据，或精确细节。通用知识笔记先提炼条件、机制、方法、验证与边界；项目参数和操作记录放在来源案例或项目文档，不让业务经历占据知识主体。
- **练习**：需要在新情境中判断、操作、表达或完成任务，单靠回忆不足以验证。

这是跨学科的共同判断，不代表所有内容都要制卡。未解决的问题保留为问题，不导出为已经证实的答案。用户未要求整理时，不在每轮教学后附加候选清单。

整理默认参考优先，再选通常 0-3 个值得主动提取的目标；一份好笔记可以没有卡。卡片应在数月后脱离原对话仍清楚、目标单一、答案易判断。长案例和整套流程主要用来练习或查阅，不默认装进日常 Anki。

参考优先和候选数量属于可调的个人工作流默认值，不是研究证明的最佳学习顺序或配额。长期记忆要看延迟提取，迁移要看有意义的变式，参考价值要看能否检索并用于任务。需要迁移学习时，让用户比较实例的关键关系并尝试应用；只展示抽象总结、生成更多卡或通过脚本检查都不能代替这些表现。

词句卡保留原句、语用、读音和可用媒体；知识卡保留机制、条件、反例与决策线索。语言学习中的通用规则也可进入知识回顾，但需要具体原句的词汇目标交给语境制卡。制卡前核对词句确实来自所给材料，示范用的新造句不能冒充原文。

## 输出与写入边界

- 先给简短、可理解的候选或处理结果。结构化 JSON 留给实际导出；除非用户要求，不把内部交接格式全部铺进聊天。
- 复用已明确的目录、语言、牌组与模型设置，不重复询问；去向确实未知且保存依赖它时才询问，不猜测外部知识库路径。
- 两个组件继续使用现有导出器及设置，牌组、卡型、历史调度和媒体规则由各自能力维护。统一入口不擅自迁移牌组、合并笔记模型或改变复习参数。
- 普通“整理/预览”只准备内容。实际导入沿用该组件的规则和本次已有授权；语境卡仍先 dry-run/prepare-only 检查 manifest，预览获批后再写入。同一范围已有明确批准时不重复索取。
- 通用回顾仅整理/导出而未授权导入时，使用 `--no-anki-import`；Runbook 使用已有明确配置或本次指定的位置。
- 音视频优先复用原字幕、转录和媒体，不为两个目标重复下载或识别。继续遵守本地能力与上传授权规则，不因接入统一入口就新增安装或联网要求。
- 区分候选已准备、文件已导出、Anki 已导入、媒体缺失等实际结果；一次仅报告必要状态，不把 TSV 或 manifest 的存在说成导入成功。

## 复习与返回学习

“今天复习”先按当前上下文及已有记录确定范围。跨领域时在一个可持续的总预算内选择项目，不把每个组件的预算依次叠加；用户已有预算优先。

沿用 Anki 或已有复习记录。需要实时到期数时只使用实际可读的数据；没有连接或记录时说明范围未知，可给离线回忆题，不伪造到期清单，也不新建一个平行调度器。

遗忘但能理解时，用提示和主动提取；概念不清时，回到例子、可视化或解释；能背却不能用时，换情境练习；题目歧义或过载时，建议改卡。修改、暂停或删除现有卡片仍依用户请求与授权处理。

恢复主题时用已有 capsule、原句/媒体定位和练习记录找回“在做什么、为什么这样理解、哪里仍有问题、下一步做什么”。用户启用的个人知识库可引用这些原始记录作为能力依据，细节继续留在原处。
